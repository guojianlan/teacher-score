## 一、产品一句话

**让一对一辅导老师用拍照的方式，让多模态 LLM 自动批改试卷并沉淀学情档案的 SaaS 工具。**

口号候选：
- 教得更准，是因为看得更清
- 试卷一拍，学情自动长

---

## 二、产品背景

### 2.1 行业观察
- 一对一辅导市场长期存在但碎片化（独立老师、小型工作室、连锁机构并存）
- 老师每周花在批改作业的时间约 5-15 小时，但**批改后的数据是孤立的**——下周备课全靠记忆
- 多模态 LLM 的能力已经能稳定覆盖"识别手写答案 + 客观题判分"的一部分场景，具体模型通过 OpenAI-compatible API 和运行时配置选择
- 教育 SaaS 普遍偏 C 端家长，针对一线老师的工具空间未被满足

### 2.2 我们看到的机会
> 一对一辅导老师的"批改"行为，是一个**每周必发生、高频、有明确痛点**的入口。
> 围绕这个入口，可以沉淀学情资产、向跨科目协作和机构客群延展。

## 三、目标用户

### 3.1 主要用户（当前核心阶段）

**一对一辅导老师**

| 维度 | 描述 |
|---|---|
| 形式 | 独立教师 / 小型工作室 / 连锁机构的兼职老师 |
| 学生规模 | 5-20 个学生（时段一对一 = 跨时段一对多） |
| 工作场景 | 办公室、家里 |
| 设备 | 电脑（笔记本为主）+ 手机 |
| 学科 | 初高中数学、英语、语文、物理、化学 |
| 主要题型 | 客观题（选择、填空）为主，含部分主观题 |
| 付费意愿 | 月付 ¥30-200 中等接受度，强 ROI 才会续费 |

### 3.2 次要用户（后续阶段）

- **培训机构主理人**：管理 5-50 个老师 + 100-1000 个学生
- **教务管理员**：分配老师 / 排课 / 看教学质量数据
- **家长**：只读访问孩子学情（长期阶段）

### 3.3 用户画像（典型代表）

**小张老师，28 岁**
- 数学专业研究生毕业，全职一对一辅导
- 手上 12 个学生，初二到高三都有
- 每周批改 30-50 份试卷（晚上 20:00-23:00 集中处理）
- 痛点：批改累、整理错题靠 Excel、家长问"孩子哪里弱"答不上来细节
- 当前付费工具：阿里云盘、印象笔记
- 期待：能省时间 + 给家长一份漂亮的学情报告

## 四、用户痛点（按优先级排序）

| 优先级 | 痛点 | 严重度 | 当前替代方案 |
|---|---|---|---|
| P0 | 批改耗时长，挤占备课和休息 | 高频 + 严重 | 手批 |
| P0 | 批改后没有结构化数据沉淀 | 高频 + 严重 | Excel 手记 |
| P1 | 错题归集和复习靠记忆 | 高频 + 中等 | 错题本子（手抄） |
| P1 | 跨科目老师之间数据不互通 | 中频 + 严重 | 互相聊微信 |
| P2 | 给家长汇报学情靠口述+截图 | 周频 + 中等 | 微信文字 |
| P2 | 难以量化教学效果 | 月频 + 严重 | 凭感觉 |

## 五、核心价值主张

**三层价值，按时间序解锁**：

### 第一层：节省时间（当前核心卖点）
- 拍照 + LLM 自动判分，客观题完全免手批
- 主观题给建议分，老师快速决策
- 量化承诺：批改提效 **50%+**

### 第二层：自动化学情档案（阶段 3 解锁）
- 每次批改自动归档到学生档案
- 错题自动归集去重
- 知识点掌握热力图自动生成
- 学情报告一键导出 PDF 给家长

### 第三层：跨场景闭环（阶段 4 与长期阶段解锁）
- 跨科目共享学生档案（机构内多老师）
- 教务看板：哪个老师批改多、哪个学生进步快
- AI 错题讲解、个性化练习推荐
- 家长端学情查看

## 六、产品愿景与演进路径

### 阶段 0 — 基础设施与端到端空链路
**目标**：先证明系统能跑通，而不是先堆页面。

- Monorepo 初始化：`apps/web` + `apps/backend` + `packages/*`
- 邮箱注册 / 登录 / personal organization 自动创建
- 学生 CRUD
- 图片上传、批改记录创建、pg-boss 入队、worker 消费测试 job
- 批改状态从 pending → processing → completed 的空链路

### 阶段 1 — 数学 + 英语核心闭环
**目标**：验证"老师愿意每周用、LLM 判分在高频题型上可用"。

- 数学、英语 prompt 与准确率 fixture
- 拍照 / 上传单页试卷
- 异步批改、轮询进度、结果审核、人工改分、置信度标注
- 错题自动归集数据写入
- 历次成绩列表
- 每月 50 次免费配额与超限提示

**衡量**：30 个种子老师，W4 留存 ≥ 40%；数学、英语高置信度题老师改分率进入可接受区间。

### 阶段 2 — 语文 + 物理 + 化学扩科
**目标**：保留完整 5 科目标，但用准确率门槛逐科放量。

- 语文：古诗默写、阅读题、作文建议分
- 物理：单位、公式、有效数字
- 化学：方程式、配平、上下标、实验题表达
- 5 科统一进入准确率回归
- 弱科可在 UI 中标注 beta，但不能偏离完整学科目标

### 阶段 3 — 学情资产化
**目标**：让老师从"省时间"进入"离不开"。

- 简化模板：保存识别结果，复用答案判分
- 错题本 UI：列表、筛选、标记已掌握
- 知识点统计、基础趋势、进步曲线
- 学情报告 PDF / 错题导出 PDF
- 主观题辅助评分优化

### 阶段 4 — 增强能力与商业化
**目标**：围绕真实使用反馈补强高成本能力。

- 手机扫码拍照联动
- 区域框选
- 多页试卷合并
- 订阅支付、家长分享链接
- 机构管理、跨老师共享学生档案、教务看板

### 长期 — 学习闭环
- 家长端只读访问
- AI 错题讲解（讲题视频/图文）
- 基于错题的个性化练习推荐
- 与排课、收费系统对接

## 七、商业模式

### 种子验证阶段 — 全免费 + 配额验证
- 注册即用，无需付费
- 每月 50 次批改额度（足够一对一辅导老师 1-2 个学生用 1 个月）
- 目的：拿真实使用数据 + 信任度
- 配额满后展示"我们正在准备付费方案"问卷收集付费意愿

### 个人订阅阶段
| 档位 | 价格 | 配额 | 学情功能 |
|---|---|---|---|
| Free | ¥0/月 | 50 次/月 | 基础 |
| Basic | ¥39/月 | 200 次/月 | 完整学情档案 |
| Pro | ¥99/月 | 无限 | + 家长分享 + PDF 导出 |
| Plus | ¥199/月 | 无限 | + 主观题深度辅助 + 多模态对比 |

### 机构采购阶段
- 按教师账号数：¥99/月/账号（年付 8 折）
- 含教务看板、数据导出、API 接入
- 机构客户起步价 ¥3000/月（含 30 教师账号）

### 单位经济测算（假设）
- 个人 Pro 用户 LTV：¥99 × 12 × 留存系数 0.5 = ¥594
- 获客成本 CAC（小红书 + 老师朋友圈裂变）：~¥80
- LTV/CAC：~7.4，健康

## 八、竞品分析

### 直接竞品

| 竞品 | 模式 | 优势 | 劣势 |
|---|---|---|---|
| 某查作业 | C 端家长向 | 学生用户量大 | 不深做老师场景 |
| 某乎批改 | OCR 强 | 识别准 | 学情薄、无机构功能 |
| 某分助手 | 题库导向 | 题库大 | 不主打批改 |
| 学而思智能批改 | 大厂内部 | 数据积累 | 仅限自家老师 |

### 我们的差异化
1. **场景定制**：专注一对一辅导老师，不做班级批改
2. **技术代差**：多模态 LLM 替代传统 OCR + 规则引擎，理解题意而非仅识字
3. **学情资产**：批改是入口，长期价值在跨次批改沉淀的档案
4. **机构友好**：从 day 1 数据模型支持机构维度（organization-based）

## 九、成功指标

### 北极星指标
**周活老师批改的卷子数 = WAU × 平均卷数/老师**

为什么是这个：
- 反映工具是否被真实使用（不是僵尸账号）
- 反映工具是否提供持续价值（不是用一次就丢）
- 与商业化指标（订阅留存）强相关

### 关键指标体系

| 阶段 | 指标 | 目标 |
|---|---|---|
| 获客 | 周新增注册老师 | ≥ 5 |
| 激活 | 注册后 7 天内完成 ≥3 次批改的比例 | ≥ 40% |
| 留存 | W4 留存（注册 4 周后仍批改的比例） | ≥ 40% |
| 留存 | 种子阶段月活老师 | ≥ 30 |
| 准确率 | 老师改分率（老师修改 LLM 判分的比例） | 高置信度题 ≤ 15% |
| 准确率 | LLM 自评高置信度的题中实际正确率 | ≥ 95% |
| 性能 | 批改 P95 时长 | ≤ 60s |
| 满意度 | NPS | ≥ 30 |
| 商业 | 付费意愿调研填写率 | ≥ 30% |

### Bad case 追踪
- 准确率监控：每周抽 20 份批改记录人工 review，统计 LLM 错误率
- 流失访谈：W2 内不再使用的老师，主动微信访谈

## 十、风险识别（产品视角）

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 5 科准确率参差，老师对弱科失望 | 高 | 高 | 透明展示置信度，弱科明确标"测试版" |
| 一对一老师太碎片，获客成本高 | 中 | 高 | 先打种子老师朋友圈，证 PMF 再投放 |
| LLM 调用成本太高，免费层亏钱 | 中 | 中 | 监控单次批改 token 成本，设上限 |
| 数据合规（学生隐私） | 中 | 高 | prompt 不传姓名，用占位符；数据本地化 |
| 老师不愿改习惯（手批已是肌肉记忆） | 中 | 中 | 强化"快"体验 + 自动 PDF 给家长，制造工具粘性 |
| LLM 模型升级导致 prompt 失效 | 低 | 中 | 模型版本固定 + 升级前 A/B 测试 |

## 十一、需要决策的开放问题

1. **机构客户什么时候开始接触？** 建议阶段 1 中后期就开始接触小工作室，不上付费但邀请 beta，提前了解机构需求
2. **是否开发微信小程序？** 阶段 4 后视移动占比决定；当前先用 Web + 手机 H5
3. **AI 讲解错题是否做？** 价值大但开发成本高，长期阶段再做
4. **老师是否能自定义 prompt？** 已决策：不允许直接自定义 prompt，但允许后续提供"评分严格度"调档
