# 教师批改 SaaS · 使用手册

> 适用对象：一对一 / 小班课老师
> 版本：W22（2026-05-31 后）
> 系统准确率：合成数据 100%；真实数据待 W23 配 vision PNG 流后测

---

## 1. 一分钟看懂

```
你的工作流：
  ① 设计答题卡 → ② 打印发给学生 → ③ 学生填完拍照
  → ④ 上传到系统 → ⑤ 等几秒看批改结果 → ⑥ 错题自动归档
```

跟传统批改的区别：

- **不用 OCR 整张试卷**，老师只需录入"标答 + 评分细则"一次
- **同一份答题卡复用**给整个班，省钱省时间
- **每个空精确判分**，不是"这题对 / 错"

## 2. 第一次用：5 步走通

### Step 1 — 学生 & 班级

1. 「学生」页面 → 添加学生（姓名 / 年级 / 学科）
2. 「班级」页面 → 新建班级 → 多选学生加入

### Step 2 — 设计答题卡

1. 「答题卡」页面 → 「+ 新建答题卡」
2. 填基本信息：名称 / 学科 / 年级 / 总分 / MCQ 列数
3. 加题目：
   - **MCQ 题**：选项（默认 ABCD）+ 正确选项
   - **结构化大题**：子问 (1)(2)(3)...，每子问加若干"空"，每个空设：
     - 标准答案
     - 等价答案（如 "叶绿体、线粒体" 也接受 "线粒体、叶绿体"）
     - 评分模式（字面一致 / 关键词命中 / 概念等价）
     - 分值
     - 关键词（仅 keyword / concept 模式用）
4. 总分要 = 各题分加起来（黄牌提示"分数不齐"）
5. 保存

### Step 3 — 打印 PDF

回到「答题卡」列表 → 点该卡的「预览」（浏览器开 PDF）→ ⌘P 打印。
> 装了 puppeteer 才出真 PDF；否则 HTML 打印也行。

### Step 4 — 学生答题 & 拍照

发给学生填，拍清楚的照片回收。

### Step 5 — 批量批改

1. 「批改」页面 → 右上「批量批改 →」
2. 选答题卡 + 选班级 → 一键给班里每个学生分配一张图片：
   - 一次拖多张图，按学生顺序自动分配
   - 单独学生也能单独上传
3. 全部就绪 → 「提交批改 (N)」
4. 跳到聚合页 `/grading-runs/[id]`，每隔 3 秒自动刷新进度
5. 完成后可：导出 CSV / 点单人看详情 / 改分

## 3. 评分模式选择参考

| 模式 | 适用 | 举例 |
|---|---|---|
| **字面一致 exact** | 短答、化学式、专有名词、数字答案 | "PGA"、"1/183"、"GGATCC" |
| **关键词命中 keyword** | 简答题（有标志性词汇）| "气孔关闭 / CO2 / 光解" 命中 3 个就接近满分 |
| **概念等价 concept** | 长论述、开放题（需 LLM 判等价）| "改造 Rubisco 避免光呼吸"（多种表达都接受）|

**调优经验**：
- keyword 模式下，关键词数量 3-5 个比较合适
- 关键词阈值：≥80% 命中视为"全对"；50-80% 给部分分；<50% 视为错
- exact 模式自动支持：全角/半角、大小写、空白、列表顺序（"A、B" = "B、A"）

## 4. 常见问题

### Q: 我已经有现成的答题卡，能直接用吗
A: 可以。系统的"答题卡"概念里"layout 渲染 PDF"是可选项——你也可以用你已有的纸质答题卡拍照上传，只要标答录入到系统的 schema 里就行。

### Q: LLM 看不清手写字怎么办
A: 系统在 `BlankExtraction.confidence` 字段标 `low` 时会在批改详情页高亮，老师可以人工改分。批改记录页有「老师改分」按钮。

### Q: 错题本怎么用
A: W23+ 功能。本期暂未实现自动归集，但每张批改记录都已保存了 `results` 字段，未来加错题本时无需重批。

### Q: PDF 渲染需要什么环境
A: 不需要任何环境就能生成 HTML（浏览器原生打印保存为 PDF 即可）。若想要服务端直出 PDF，装：
```bash
pnpm add -F @teacher-score/pdf puppeteer
```

### Q: 准确率怎么验证
A: 跑：
```bash
pnpm synth:sheet --count=30        # 合成 30 张测试答题卡
pnpm e2e:grading                   # 跑评分引擎对比
```
当前合成数据 100% 准确（评分逻辑层面）。真实数据准确率取决于 LLM 视觉识别能力。

## 5. 命令速查（运维 / 排查）

```bash
# 开发
pnpm dev                          # 起 web + backend + worker

# 数据库
pnpm db:generate                  # 改 schema 后生成 migration
pnpm db:migrate                   # 应用迁移

# 答题卡工具
pnpm seed:bio                     # 把样本生物卷 seed 到 DB
pnpm synth:sheet --count=10       # 合成 10 张测试答题卡
pnpm e2e:grading                  # 跑评分准确率验证
pnpm e2e:grading --use-llm        # 真调 LLM（要有 PNG）

# 设计系统
pnpm tokens:sync                  # 改 token.json 后同步
pnpm tokens:audit                 # WCAG 校验
pnpm tokens:add-color teal "#0F766E"  # 加新色族
```

## 6. 已知限制

| 限制 | 缓解 |
|---|---|
| LLM 视觉识别中文手写仍可能错 | 详情页可改分，confidence=low 高亮 |
| 答题卡 PDF 排版较简陋 | 下一版加 react-pdf 替代 HTML |
| 错题本未自动归集 | W23+ |
| 单文件 schema 上限 ≤80 题 / 上传 ≤80 学生 | 通常一卷一班够用 |
| 不支持图像选择题 / 涂卡 OMR | LLM 视觉够用就先不做 |
