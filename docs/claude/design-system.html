两层架构

Base tokens（base.ts）—— 原料：色阶、字体、字号、间距、圆角等。业务代码不直接使用。

Semantic tokens（semantic.ts）—— 语义化命名：bg.canvas、fg.default、interactive.primary.bg。所有组件 / 页面只用这一层。切换 light/dark 主题只需重新映射这一层，业务代码零修改。

Text styles（text-styles.ts）—— 命名组合样式：display.lg、body.md、overline。JSX 里 <Text textStyle="body.md"> 直接引用。

改 token 后跑 pnpm tokens:build 重新生成 CSS 变量和这份文档。
